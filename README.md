# پرنده کوچولو | Little Parandeh

فروشگاه مفهومی لباس کودک با تم روشن، رنگ‌های پاستلی و رابط فارسی RTL. پروژه به‌صورت استاتیک ساخته شده و روی GitHub Pages یا هر هاست استاتیک اجرا می‌شود.

## صفحات

- `index.html` — خانه
- `shop.html` — فروشگاه با فیلتر زنده سن، دسته‌بندی، جست‌وجو و مرتب‌سازی
- `product.html` — جزئیات محصول با انتخاب رنگ، سایز، گالری و Accordion
- `size-guide.html` — پیشنهاد سایز بر اساس سن و قد (محاسبه‌ی ساده‌ی دمو)
- `about.html` — درباره برند
- `blog.html` و `article.html` — مجله والدین و مقاله
- `cart.html` — سبد خرید متصل به `localStorage`
- `contact.html` — فرم دمو با اعتبارسنجی مرورگر
- `404.html` — صفحه خطا

## اجرای محلی

۱. ZIP را استخراج کنید.
۲. فایل `index.html` را باز کنید یا از افزونه Live Server در VS Code استفاده کنید.
۳. برای دسترسی کامل به تمام قابلیت‌ها، بهتر است سایت با یک وب‌سرور محلی ساده اجرا شود.

هیچ مرحله Build یا وابستگی JavaScript خارجی وجود ندارد. فونت‌ها از Google Fonts و عکس‌ها از Unsplash بارگذاری می‌شوند؛ برای نمایش آن‌ها اتصال اینترنت لازم است. لینک تصاویر مستقیم هستند و در فایل‌های HTML/JS قابل تعویض‌اند.

## انتشار در GitHub Pages

۱. تمام محتویات پوشه را در ریشه‌ی یک GitHub Repository قرار دهید.
۲. وارد `Settings → Pages` شوید.
۳. گزینه `Deploy from a branch` را انتخاب کنید.
۴. شاخه `main` و پوشه `/root` را تنظیم و ذخیره کنید.
۵. آدرس انتشار را بررسی کنید.

## تنظیمات پیش از انتشار

- دامنه‌ی نمونه `littleparandeh.example` را در `sitemap.xml` و `robots.txt` با دامنه‌ی واقعی عوض کنید.
- در صورت نیاز، canonical و اطلاعات شبکه‌های اجتماعی واقعی اضافه کنید.
- تصاویر و مشخصات هر محصول را با محتوای دارای مجوز و تأییدشده جایگزین کنید.
- برای سفارش واقعی، API/Backend، درگاه پرداخت، مدیریت موجودی، قوانین ارسال و حریم خصوصی لازم است.

## نکات فنی و محدودیت‌ها

- محصولات، قیمت‌ها، موجودی، ترکیبات پارچه، نشان «پنبه ۱۰۰٪»، اطلاعات تماس و متن‌ها نمایشی هستند.
- سبد خرید صرفاً در مرورگر با `localStorage` ذخیره می‌شود؛ بین دستگاه‌ها همگام نیست.
- فرم تماس فقط اعتبارسنجی سمت مرورگر انجام می‌دهد و چیزی را ارسال نمی‌کند.
- راهنمای سایز یک تخمین ساده و نمونه است و نباید جایگزین جدول اندازه‌گیری تولیدکننده شود.
- تصاویر از Unsplash با URL مستقیم بارگذاری می‌شوند. پیش از استفاده تجاری، مجوز و تناسب هر تصویر را بررسی و در صورت نیاز با عکاسی اختصاصی جایگزین کنید.
- در پروژه از Vanilla JS استفاده شده؛ کتابخانه‌ی سنگین یا مرحله‌ی Compile وجود ندارد.
